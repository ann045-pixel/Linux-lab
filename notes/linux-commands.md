# Основные команды Linux

## Навигация
- `pwd` — показать текущую папку
- `ls -la` — список файлов (включая скрытые)
- `cd ~` — перейти в домашнюю папку
- `cd ..` — подняться на уровень выше

## Работа с файлами
- `cat file` — показать содержимое файла
- `less file` — постраничный просмотр
- `head -5 file` — первые 5 строк
- `tail -f file` — следить за логом в реальном времени
- `cp file1 file2` — копировать файл
- `mv file1 folder/` — переместить файл
- `mkdir -p a/b/c` — создать вложенные папки

## Поиск
- `grep "text" file` — найти строки с текстом
- `grep -r "text" ./` — искать рекурсивно
- `find / -name "*.conf"` — найти файлы по имени

## Процессы
- `ps aux` — список процессов
- `top` — мониторинг процессов
- `kill -9 PID` — убить процесс
- `systemctl start/stop/status service` — управление службами

## Права доступа
- `chmod +x script.sh` — сделать файл исполняемым
- `chmod 755 file` — права: rwxr-xr-x
- `chown user:group file` — сменить владельца

## Сеть
- `ip a` — посмотреть IP-адреса
- `ss -tulpn` — посмотреть открытые порты
- `ping google.com` — проверить доступность хоста
- `curl ifconfig.me` — узнать внешний IP

## Работа с Git
- `git status` — проверить состояние репозитория
- `git add .` — добавить все изменения
- `git commit -m "message"` — зафиксировать изменения
- `git push` — отправить на GitHub
- `git pull` — получить изменения
- `git branch` — список веток
- `git checkout -b new-branch` — создать ветку
