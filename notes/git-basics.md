# Основы Git

## Что такое Git
Система контроля версий, которая позволяет отслеживать изменения в коде и работать в команде.

## Основные команды

### Настройка
- `git config --global user.name "Your Name"`
- `git config --global user.email "email@example.com"`

### Инициализация
- `git init` — создать локальный репозиторий
- `git clone <url>` — скопировать удалённый репозиторий

### Работа с изменениями
- `git status` — посмотреть текущее состояние
- `git add <file>` — добавить файл под версионный контроль
- `git add .` — добавить все изменённые файлы
- `git commit -m "message"` — зафиксировать изменения
- `git log` — история коммитов

### Ветки
- `git branch` — список веток
- `git checkout <branch>` — переключиться на ветку
- `git checkout -b <branch>` — создать новую ветку
- `git merge <branch>` — влить ветку в текущую

### Удалённый репозиторий
- `git remote add origin <url>` — привязать удалённый репозиторий
- `git push` — отправить изменения
- `git pull` — скачать изменения

## Типичные ошибки
- `git push rejected` — нужно сделать `git pull`
- `merge conflict` — конфликт при слиянии, решается вручную
